Project

Farm Eyes

Farm Eyes detects and diagnoses plant diseases from photos. We're weighing three ways to build it:

Farm Eyes ตรวจจับและวินิจฉัยโรคของพืชจากภาพถ่าย โดยกำลังพิจารณา 3 แนวทางในการพัฒนา

chat

Chat Bot

check_circle Can answer follow-up questions about the diagnosed disease.

warning Model training process is more complex.

smartphone

App / Web App (YOLO)

check_circle Faster and simpler to develop using an object detection model like YOLO.

warning Users only see the disease name, with no further explanation.

link

YOLO + LLM Pipeline

check_circle YOLO classifies the disease, then hands off to an LLM to continue the conversation.

warning Needs two models wired together, adding integration complexity.
